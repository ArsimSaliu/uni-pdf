# Privacy

**Short version: uni-pdf never sees your files or your notes.**

- uni-pdf is a set of static files (HTML, CSS, JavaScript) that runs entirely in your web browser. There is no uni-pdf server, account system or database.
- PDFs you open and the notes you write are stored on your own device, in your browser's IndexedDB storage. They are never uploaded anywhere.
- There are no analytics, trackers, cookies, ads, or third-party scripts. All libraries are bundled with the app, so it makes no requests to other websites.
- The hosted version is served by GitHub Pages. Like any web host, GitHub may log basic request data (such as IP address and pages requested) when your browser downloads the app files. See [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The offline download avoids this completely.
- Your data is deleted when you remove a PDF from the library or clear this site's data in your browser settings. Export a backup first if you want to keep it.
- Exports (PDF, Markdown, JSON) are generated on your device and saved wherever you choose.

Questions? [Open an issue](https://github.com/ArsimSaliu/uni-pdf/issues).
