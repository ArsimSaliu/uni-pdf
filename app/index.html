    Keyboard shortcuts

    ← →Previous / next page
    + - 0Zoom in / out / fit width (or Ctrl + scroll)
    HHighlight the selected text
    NHighlight the selection and write a note
    A or Alt + dragArea note: box a diagram, formula or image
    PWrite notes for the current page
    \Hide / show the notes panel
    L / OLibrary / open a PDF
    EscLeave a text box, close menus
    ?This help

    Good to know

    • Notes save automatically, in this browser only. Use Export → Backup before clearing browser data or switching computers.
    • Export → Editable PDF gives you one file that has both the slides and your notes. Open it here again, on any computer, to keep editing.
    • Opening the same PDF again, even from another folder, brings back its notes.
